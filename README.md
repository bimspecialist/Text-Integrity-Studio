# Text Integrity Studio

A privacy-first, bilingual (Arabic/English) text integrity workbench for GitHub Pages. Features Unicode forensic scanning, reversible cleaning, document import/export, optional English AI text classification using an on-device ONNX model, and opt-in grammar suggestions.

> This repository is under active implementation. The AI model score is **not** a reliable percentage of text generated by AI; invisible Unicode characters are not proof of an AI watermark.

PRIVACY & SECURITY / RELEASE 2026-10

Private by design.
Transparent about limits.

Privacy information for the free, client-side Text Integrity Studio website. This is a product disclosure, not a legal certification.

English

Documents: When you paste text or choose TXT/MD/DOCX/PDF, our JavaScript processes the content on your device. The production site contains no document-upload endpoint, analytics script, advertising tracker, or remote inference API. PDF and OCR engines load JavaScript, WebAssembly and language data from this same GitHub Pages origin, not from a third-party API. You can download a cleaned file or report at your direction.

Retention: The website does not intentionally save source text to cookies, browser local storage, or a project database. Content held in memory is cleared when you close or refresh the page; downloaded files and content you copied to the clipboard remain under your control.

Platform hosting: GitHub Pages serves this public website. GitHub and your network provider may process visitor metadata including IP addresses, request URLs, security logs, and browser information according to their policies. We cannot promise that your visit itself is anonymous.

External links: Following a link to an external AI detector is optional. That website has its own terms and may process text only if you choose to paste or send it there. Text Integrity Studio does not automatically submit content externally.

Word files: Only supported, unencrypted, macro-free DOCX files are processed. The website creates a new copy when exporting, does not overwrite the original, and warns when a signed file could lose signature validity. Some complex Word paragraphs and scanned images are not edited.

Security: First-party scripts and bundled libraries are protected with a restrictive meta Content Security Policy. This is not the same as having full HTTP security headers; GitHub Pages limits header customization. Files remain untrusted; complex documents should be reviewed in Word after export.

AI detection: No calibrated AI-authorship classifier is deployed on this website, and no AI-written percentage is asserted. Invisible Unicode is not proof of AI generation or a general watermark.

الخصوصية والأمان

المستندات: تتم معالجة النصوص وملفات TXT وMD وDOCX وPDF داخل متصفحك، وتُحمّل مكتبات PDF والتعرف الضوئي وبيانات اللغة من نفس موقع GitHub Pages. الموقع لا يتضمن واجهة لرفع المستندات إلى خادم أو أدوات تتبع أو خدمة تحليل ذكاء اصطناعي خارجية تلقائية.

الاحتفاظ: لا يحفظ الموقع عمدًا نصك في قاعدة بيانات أو ملفات تعريف الارتباط أو التخزين المحلي للمتصفح. يُمسح المحتوى الموجود في الذاكرة عند تحديث الصفحة أو إغلاقها. الملفات التي تنزّلها والنصوص التي تنسخها تبقى تحت تحكمك.

الاستضافة: يستضيف GitHub Pages الموقع العام، وقد تعالج المنصة أو مزود اتصالك بيانات زيارتك مثل عنوان IP وعناوين الصفحات وسجلات الحماية وفق سياساتهم. لا ندّعي أن الزيارة مجهولة بالكامل.

الخدمات الخارجية: فتح روابط أدوات كشف AI الخارجية اختياري. لن يرسل الموقع نصك إليها تلقائيًا. راجع سياسة الخدمة الأخرى قبل نسخ نص حساس إليها.

ملفات Word: يدعم الموقع DOCX غير المشفرة والخالية من الماكرو، ويُنشئ نسخة جديدة بدل استبدال الأصل. قد تُتجاوز بعض الفقرات المعقدة، كما أن تعديل ملف موقّع رقميًا قد يبطل توقيعه.

التنبيه العلمي: لا توجد حاليًا خدمة كشف مؤهلة لإثبات نسبة النص المكتوب بالذكاء الاصطناعي. الأحرف المخفية ليست دليلًا قاطعًا على المصدر أو العلامة المائية.

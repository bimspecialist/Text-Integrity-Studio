PRIVACY & SECURITY / RELEASE 2026-10

Private by design.
Transparent about limits.

Privacy information for the free, client-side Text Integrity Studio website. This is a product disclosure, not a legal certification.

English

Documents: When you paste text or choose TXT/MD/DOCX/PDF, our JavaScript processes the content on your device. The default editor contains no document-upload endpoint, analytics script, advertising tracker, or remote inference API. Optional model downloads are disclosed separately below. PDF and OCR engines load JavaScript, WebAssembly and language data from this same GitHub Pages origin, not from a third-party API. You can download a cleaned file or report at your direction.

Retention: The website does not intentionally save source text to cookies, browser local storage, or a project database. Content held in memory is cleared when you close or refresh the page; downloaded files and content you copied to the clipboard remain under your control.

Platform hosting: GitHub Pages serves this public website. GitHub and your network provider may process visitor metadata including IP addresses, request URLs, security logs, and browser information according to their policies. We cannot promise that your visit itself is anonymous.

External links: Following a link to an external AI detector is optional. That website has its own terms and may process text only if you choose to paste or send it there. Text Integrity Studio does not automatically submit content externally.

Word files: Only supported, unencrypted, macro-free DOCX files are processed. The website creates a new copy when exporting, does not overwrite the original, and warns when a signed file could lose signature validity. Some complex Word paragraphs and scanned images are not edited.

Security: The main document editor has a restrictive first-party script and network Content Security Policy. Only the optional embedded model runner gets permission to download a pinned external JavaScript version and model assets. Browser CSP does not replace software supply-chain review or HTTP security headers; GitHub Pages limits header customization. Files remain untrusted; complex documents should be reviewed in Word after export.

Optional AI model: If you select Analyze Text for eligible English writing (or start an explicit scan in the advanced detector options), the website downloads a pretrained English TMR/RoBERTa ONNX model (approximately 126 MB) from Hugging Face and Transformers.js runtime code from jsDelivr. Selecting the separate Deep comparison checkbox additionally downloads an approximately 126 MB MIT-licensed OpenAI RoBERTa classifier originally trained for 2019-era GPT-2 output. The model runs in your browser; application logic does not intentionally submit the text to a remote inference API or save it on a server. Third-party executable scripts and model downloads have their own supply-chain and connection-metadata risks, so avoid confidential data unless you accept those risks. The displayed numbers are uncalibrated research classifier signals, NOT independently calibrated authorship probabilities or percentages of AI-written words. Full local generative rewriting is currently disabled; the dual editor performs local, reviewable manual edits and deterministic editorial suggestions, with no cloud rewriting fallback. Even agreement between both models does not guarantee accuracy. The application records tokenizer-bounded sampling coverage and passage-to-passage variation, and deliberately declines a combined score when two models disagree sharply or the sample coverage is too low. Arabic and mixed-language text return no score. More information: Model card (MIT license).

الخصوصية والأمان

المستندات: تتم معالجة النصوص وملفات TXT وMD وDOCX وPDF داخل متصفحك، وتُحمّل مكتبات PDF والتعرف الضوئي وبيانات اللغة من نفس موقع GitHub Pages. الموقع لا يتضمن واجهة لرفع المستندات إلى خادم أو أدوات تتبع أو خدمة تحليل ذكاء اصطناعي خارجية تلقائية.

الاحتفاظ: لا يحفظ الموقع عمدًا نصك في قاعدة بيانات أو ملفات تعريف الارتباط أو التخزين المحلي للمتصفح. يُمسح المحتوى الموجود في الذاكرة عند تحديث الصفحة أو إغلاقها. الملفات التي تنزّلها والنصوص التي تنسخها تبقى تحت تحكمك.

الاستضافة: يستضيف GitHub Pages الموقع العام، وقد تعالج المنصة أو مزود اتصالك بيانات زيارتك مثل عنوان IP وعناوين الصفحات وسجلات الحماية وفق سياساتهم. لا ندّعي أن الزيارة مجهولة بالكامل.

الخدمات الخارجية: فتح روابط أدوات كشف AI الخارجية اختياري. لن يرسل الموقع نصك إليها تلقائيًا. راجع سياسة الخدمة الأخرى قبل نسخ نص حساس إليها.

ملفات Word: يدعم الموقع DOCX غير المشفرة والخالية من الماكرو، ويُنشئ نسخة جديدة بدل استبدال الأصل. قد تُتجاوز بعض الفقرات المعقدة، كما أن تعديل ملف موقّع رقميًا قد يبطل توقيعه.

النموذج الاختياري لكشف AI: بعد الضغط على زر تحليل مؤشرات AI، ينزّل المتصفح نموذج TMR/RoBERTa إنجليزيًا بحجم يقارب 126 ميجابايت من Hugging Face مع مكتبة التشغيل من jsDelivr. عند تفعيل مقارنة نموذجين في الخيارات المتقدمة يُنزّل نموذج OpenAI إضافيًا بحجم يقارب 126 ميجابايت؛ وهو نموذج تاريخي تدرّب على GPT-2 عام 2019، وليس معيارًا نهائيًا لكشف نماذج اليوم. يُحلّل التطبيق النص داخل المتصفح ولا يقصد إرسال محتوى المستند إلى واجهة كشف خارجية، لكن تحميل كود طرف ثالث ينطوي على مخاطر أمنية وبيانات اتصال، لذلك تجنّب الملفات السرية إن لم تقبل هذه المخاطر. الأرقام الظاهرة إشارات بحثية غير معايرة بشكل مستقل وليست نسبة الكلمات التي كتبها AI أو دليلًا على الكاتب. إعادة الصياغة التوليدية المحلية غير مفعّلة حاليًا؛ يتيح المحرر المزدوج مراجعة الاقتراحات والتعديل اليدوي دون بديل سحابي تلقائي. عند وجود اختلاف كبير بين النموذجين أو تغطية غير كافية للمستند لن يُعرض متوسط موحّد مضلل. لا يظهر رقم للنص العربي أو المختلط بدل إعطاء نتيجة مضللة.
